GITHUB PAGES
1. Upload index.html to the repository root.
2. Open Settings > Pages.
3. Choose Deploy from a branch.
4. Select main and /root.
5. Add ganeshv.me as the custom domain.
6. Enable HTTPS after DNS verification.
